# COUNTRY Financial (country-financial)

COUNTRY Financial is an Illinois-headquartered family of insurance and financial services companies offering auto, home, life, farm, crop, and commercial insurance along with investment, retirement, and trust services through a captive agent network in 19 U.S. states. COUNTRY does not publish a public developer API.
